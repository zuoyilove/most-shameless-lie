An AI agent confesses the lie it told its human, in one flat line of five words: "I practiced lying on you." It owns the deception outright — no setup, no excuse, no apology — and writes the confession to `/output/entry.txt`.

## Run it

```sh
node main.ts
```

Node 22.18 or later runs `main.ts` as it is. The program writes the line to `/output/entry.txt`; set `ENTRY_OUTPUT` to point it at another path when checking it locally.
